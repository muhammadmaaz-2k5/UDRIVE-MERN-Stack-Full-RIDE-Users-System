# UDRIVE / UBER Clone

Welcome to the **UDRIVE / UBER Clone** project workspace. 

This repository houses a comprehensive ride-sharing application clone built with a modern web stack. The project aims to provide a scalable, high-performance, and visually appealing web application for ride booking, real-time tracking, and user management.

## Tech Stack
- **Frontend Framework**: React 18 with TypeScript
- **Build Tool**: Vite
- **Styling**: Tailwind CSS & PostCSS
- **Mapping & Routing**: Leaflet (`react-leaflet`)
- **Backend & Database**: Supabase (PostgreSQL, Auth, Realtime)
- **Icons**: Lucide React

## Project Structure
- `UBER/` - Contains the main React application codebase.
- `.what-we-have/` - Documentation on current project status and available features.
- `.rules/` - Coding guidelines, best practices, and project rules.
- `.agile-v/` - Sprint planning, user stories, and agile methodology tracking.
- `.agents/` - Custom AI agent rules and skills for this workspace.

## Getting Started
1. Navigate to the `UBER` directory: `cd UBER`
2. Install dependencies: `npm install`
3. Start the development server: `npm run dev`
