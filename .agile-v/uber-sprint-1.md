# Sprint 1: Foundation & Setup

## Objective
Establish the fundamental project structure, set up the backend database schemas, and create the core layout for the ride-sharing application.

## Backlog / User Stories
- **[Task]** Initialize the React + Vite frontend and verify Tailwind setup. (Completed)
- **[Task]** Set up Supabase project and link it to the frontend via a `supabaseClient`.
- **[Task]** Design the initial UI layout including navigation, sidebar, and map placeholder.
- **[User Story]** As a user, I want to see a full-screen interactive map so I can know where I am and where I want to go.
- **[User Story]** As a user, I want to be able to sign up or log in using email/password so my account is secure.

## Acceptance Criteria
- App compiles without errors (`npm run build`).
- User can view a basic map interface.
- Authentication pages (Login/Signup) are visually complete.
