# Antigravity Rules: UI & Aesthetics

1. **Vanilla CSS First**: Prioritize Vanilla CSS for styling. Use CSS variables in a `variables.css` file for color palettes, spacing, and typography.
2. **Premium Design**: Ensure a "WOW" factor. Avoid generic solid colors. Incorporate glassmorphism (backdrop-blur, subtle borders) and smooth gradients.
3. **Animations**: Always include micro-interactions. Use smooth transitions on hover, focus, and state changes.
4. **Typography**: Use modern Google Fonts (e.g., Inter, Outfit) and ensure clear hierarchical structure in font sizes and weights.
5. **No Placeholders**: Never leave placeholder images. Generate assets using the image generation tool if necessary.
