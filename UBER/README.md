# UBER Ride-Sharing Web App

This is a modern ride-sharing web application built with React, Vite, and Tailwind CSS. It leverages Supabase for backend services (Authentication, Database, Realtime) and Leaflet for interactive maps and routing.

## Features (Planned/In-Progress)
- **User Authentication**: Secure signup and login using Supabase Auth.
- **Interactive Maps**: Real-time map rendering and route calculation using Leaflet.
- **Ride Booking**: Requesting rides, setting pickup/drop-off locations.
- **Real-Time Tracking**: Live tracking of drivers and ride status via Supabase Realtime.
- **Responsive Design**: Mobile-first, sleek UI built with Tailwind CSS and Lucide React icons.

## Available Scripts

In the project directory, you can run:

### `npm run dev`
Runs the app in the development mode.
Open [http://localhost:5173](http://localhost:5173) to view it in the browser.

### `npm run build`
Builds the app for production to the `dist` folder.

### `npm run lint`
Runs ESLint to check for code quality and style issues.
